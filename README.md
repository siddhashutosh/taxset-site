# TaxSet — legal pages

The privacy policy and support page for **TaxSet**, a privacy-first quarterly tax set-aside
estimator for freelancers and self-employed people.

App Store Connect requires both as publicly reachable URLs, and the app links to them from
Settings. This repository exists only to serve them; the app's own source is private.

- [Privacy policy](https://siddhashutosh.github.io/taxset-site/privacy.html)
- [Support](https://siddhashutosh.github.io/taxset-site/support.html)

> These files are **copies**. The originals live in `docs/` in the app repository and are versioned
> alongside the code they describe — a privacy policy that drifts from the app it documents is worse
> than no privacy policy. Edit them there, then run `npm run site` to publish.
